Шрифти для PDF-звітів (Analytics Pro)

NotoSans-Regular.ttf, NotoSans-Bold.ttf: Noto Sans, підтримка латиниці, кирилиці (українська) і грецької.
Автори: The Noto Project Authors. Ліцензія: SIL Open Font License 1.1 (текст у файлі OFL.txt у цій папці).
Джерело файлів: https://github.com/notofonts/notofonts.github.io (fonts/NotoSans/hinted/ttf); ліцензія: https://github.com/notofonts/latin-greek-cyrillic

Використання: файли вантажаться браузером лише під час формування PDF (report-ui.js); у PDF вбудовується ПІДМНОЖИНА використаних гліфів (report-pdf.js).
Шрифти не змінюються й не перейменовуються. OFL дозволяє вбудовувати їх у документи й поширювати разом із програмою за умови збереження цього повідомлення та тексту ліцензії.
