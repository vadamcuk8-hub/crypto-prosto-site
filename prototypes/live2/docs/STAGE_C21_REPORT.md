## 2. Що зроблено
**R1.** `paper_step(st, events, ctx, ptf, kb, now, books=None) → (новий стан, новий журнал, результат)`. Тіло взято з `paper_update` без змін (порядок обчислень, округлення, структура JSON, порядок подій, відкрита свічка). Чиста: не читає й не пише файли, не звертається до мережі, годинника й `load/write_json/outlook_context`; вхідні `st`, `events` не змінює (працює з `deepcopy`). `paper_update(ptf, kb, now, tag)` лишилась із тим самим підписом і порядком: `load(стан)` → `outlook_context()` → `load(журнал)` → крок → `write_json(стан)` → `write_json(журнал)`.

**R2.** `Costs(kb, cap, books=None)`: `None` → глобальна `BOOKS` (читається в момент виклику, як і раніше); словник (навіть порожній) → книги лише з нього. Старі виклики `Costs(kb, cap)` і глобальна `BOOKS` працюють як раніше (`run()` не чіпали).
