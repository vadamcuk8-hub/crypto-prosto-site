# Підключення тестової біржі й Telegram (крок за кроком)

Усе нижче безкоштовне й працює на **ненастоящих грошах**. Ключі вводяться ТІЛЬКИ в налаштуваннях GitHub. Не пишіть їх у чат, у файли сайту чи в листи.

---

## Частина 1. Тестова біржа Binance (Testnet)

### Крок 1. Отримати ключі
1. Відкрийте https://testnet.binance.vision
2. Натисніть **Log in with GitHub** і увійдіть своїм акаунтом GitHub.
3. Натисніть **Generate HMAC_SHA256 Key**.
4. Дайте ключу назву (наприклад, `crypto-prosto`) і натисніть **Generate**.
5. З'являться два рядки: **API Key** і **Secret Key**.
   - **Secret Key показується один раз.** Скопіюйте його одразу в безпечне місце (наприклад, менеджер паролів). Якщо загубите, створіть новий ключ.
6. Тестовий рахунок отримує віртуальні гроші автоматично (USDT, BTC та інші). Реальних коштів тут нема.

### Крок 2. Додати ключі в GitHub
1. Відкрийте свій репозиторій на GitHub: `github.com/vadamcuk8-hub/crypto-prosto-site`
2. **Settings** (вгорі) → ліворуч **Secrets and variables** → **Actions**.
3. Натисніть **New repository secret**:
   - **Name:** `BINANCE_TESTNET_API_KEY`  
     **Secret:** вставте API Key → **Add secret**
4. Ще раз **New repository secret**:
   - **Name:** `BINANCE_TESTNET_API_SECRET`  
     **Secret:** вставте Secret Key → **Add secret**

Назви пишіть точно так, великими літерами.

### Крок 3. Запустити й перевірити
1. Вкладка **Actions** → зліва «Оновлення даних і публікація» → **Run workflow** → **Run workflow**.
2. Зачекайте 2–3 хвилини, поки з'явиться зелена галочка.
3. Відкрийте сайт → **Симуляція** → кнопка **Тестова біржа**. Мають з'явитись рахунок, позиції й ордери.
4. Далі бот працює сам кожні ~10 хвилин.

### Якщо щось не так
| Що бачите | Що робити |
|---|---|
| «Тестова торгівля вимкнена: немає ключів» | Секрети не додані або назви з помилкою. Перевірте обидва. |
| Помилка авторизації / «Invalid API-key» | Скопіювали з зайвим пробілом або не весь ключ. Створіть новий ключ і додайте секрет заново. |
| Порожньо, хоча ключі є | Дочекайтесь наступного запуску (10 хв) і натисніть Ctrl+F5. |
| Хочу почати з чистого рахунку | На testnet.binance.vision можна скинути тестовий баланс. |

Бот працює лише з адресою `testnet.binance.vision` і **не може** вийти на справжню біржу, навіть якщо вставити туди справжні ключі: це захищено в коді.

## Частина 2. Сповіщення в Telegram (необов'язково)

### Крок 1. Створити бота
1. У Telegram знайдіть **@BotFather** і напишіть `/newbot`.
2. Дайте назву й унікальне ім'я (закінчується на `bot`).
3. BotFather надішле **токен** (довгий рядок). Збережіть його приватно.

### Крок 2. Дізнатись свій chat id
1. Знайдіть **@userinfobot** і натисніть Start: він покаже ваш числовий **Id**. Це і є `chat id`.
2. Відкрийте свого нового бота й натисніть **Start** (інакше він не зможе вам писати).

### Крок 3. Додати секрети в GitHub
Як у Частині 1, Крок 2:
- `TELEGRAM_BOT_TOKEN` = токен від BotFather
- `TELEGRAM_CHAT_ID` = ваш Id

### Крок 4. Перевірити
Запустіть **Actions → Run workflow**. Через кілька хвилин у Telegram прийде привітання «Сповіщення підключено». Далі приходитимуть купівлі й продажі віртуальних ботів (максимум 6 повідомлень за запуск) і підсумок раунду. У кожному повідомленні є застереження, що це симуляція, а не порада.

Які правила надсилати, змінюється у файлі `knowledge/notify.json`.

---

## Безпека (важливо)
- Секрети видно лише вам у GitHub, а в код і на сайт вони не потрапляють.
- Якщо випадково показали ключ чи токен комусь, видаліть його (на testnet або в @BotFather командою `/revoke`) і створіть новий.
- Для справжньої біржі такі ключі не створюйте й не додавайте: наш бот для неї не призначений.
